# ml-learning

Prácticas de Machine Learning en Python.

## Notebooks

- `01_regresion_lineal_desde_cero.ipynb`  
  Implementación manual de regresión lineal simple y descenso de gradiente.

- `02_regresion_lineal_sklearn.ipynb`  
  Entrenamiento del mismo modelo usando `scikit-learn` y comparación con la implementación manual.

- `03_regresion_logistica_desde_cero.ipynb`  
  Implementación manual de regresión logística, función sigmoide, función de coste logarítmica y descenso de gradiente.

- `04_regresion_logistica_sklearn.ipynb`  
  Entrenamiento de regresión logística con `scikit-learn` y comparación con la implementación manual.

## Objetivo

Aprender cómo funcionan los modelos de Machine Learning internamente antes de utilizar librerías de alto nivel, y validar los resultados utilizando herramientas estándar como `scikit-learn`.
