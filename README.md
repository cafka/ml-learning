# 🧠 ml-learning

Prácticas de Machine Learning en Python y bitácora personal de estudio sobre Machine Learning, redes neuronales, álgebra lineal, programación científica y fundamentos matemáticos.

Este repositorio documenta un recorrido de aprendizaje progresivo: primero entender cómo funcionan los modelos internamente, luego utilizar librerías estándar y finalmente construir proyectos aplicados.

---

# 📓 Notebooks

- `01_regresion_lineal_desde_cero.ipynb`  
  Implementación manual de regresión lineal simple y descenso de gradiente.

- `02_regresion_lineal_sklearn.ipynb`  
  Entrenamiento del mismo modelo usando `scikit-learn` y comparación con la implementación manual.

- `03_regresion_logistica_desde_cero.ipynb`  
  Implementación manual de regresión logística, función sigmoide, función de coste logarítmica y descenso de gradiente.

- `04_regresion_logistica_sklearn.ipynb`  
  Entrenamiento de regresión logística con `scikit-learn` y comparación con la implementación manual.

---

# 🎯 Objetivo

Aprender cómo funcionan los modelos de Machine Learning internamente antes de utilizar librerías de alto nivel, y validar los resultados utilizando herramientas estándar como `scikit-learn`, `NumPy`, `TensorFlow` y laboratorios en Jupyter.

El enfoque no es solamente “usar herramientas”, sino entender:

- cómo funcionan los modelos,
- qué optimizan,
- cómo representan información,
- cómo se implementan internamente,
- y cómo se conectan los fundamentos matemáticos con la práctica en Python.
